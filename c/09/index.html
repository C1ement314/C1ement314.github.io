9.3.2 数组越界

C 语言不会自动检查数组下标是否越界。

合法下标只有：

访问 a[5]、a[-1] 都是越界，属于未定义行为。

越界的后果可能包括：

  • 程序崩溃；
  • 输出错误结果；
  • 修改到其他变量的值；
  • 看似正常运行，但在别的平台或优化级别下出问题。

所以写数组代码时，一定要确认：

  1. 下标从哪里开始；
  2. 下标到哪里结束；
  3. 循环条件用 < 还是 <=；
  4. 数组长度和循环边界是否一致。

冒泡排序的思想是：

每一轮把当前未排序部分中的最大或最小元素“冒”到末尾。

对于 n 个元素，冒泡排序通常需要大约 n² 次比较，属于 O(n^2) 复杂度。

初学阶段先掌握基本写法，后面学算法时再优化。

选择排序

选择排序的思路是：

每一轮从未排序部分中选出最小值，放到已排序部分的末尾。

和冒泡排序相比：

  • 冒泡排序交换次数可能更多；
  • 选择排序每轮只交换一次；
  • 两者时间复杂度通常都是 O(n^2)。

一句话总结

数组是一组相同类型元素的连续存储空间；下标从 0 开始，遍历时注意 i < count，数组作为函数参数时会退化为指针，必须额外传入长度，访问数组前一定要确认边界。
