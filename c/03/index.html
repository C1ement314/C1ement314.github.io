3.2.5 用 fgets 读取一行文本

如果要读取一行文字，fgets 通常比 scanf 更合适。

fgets 的三个参数是：

  • 第一个参数：把读到的内容存到哪里；
  • 第二个参数：最多能存多少；
  • 第三个参数：从哪个输入流读，键盘输入用 stdin。

fgets 的特点：

  1. 它最多读取 size - 1 个字符；
  2. 读完会自动在末尾补上字符串结束符 \0；
  3. 如果这一行没有超过缓冲区大小，它通常会把换行符也读进去；
  4. 读取失败或没有读到任何字符时，返回 NULL。

3.3.5 fgets 和 scanf 的差异

这是本章最重要的对比。

对比项 scanf fgets
主要用途 按格式读取输入 读取一行文本
读取字符串 %s 遇到空白停止 可以读取空格
缓冲区安全 %s 需要自己限制宽度 通过 size 限制长度
换行符 通常留在输入缓冲区 通常会把换行符读进去
返回值 成功赋值的项数 成功时返回缓冲区指针，失败返回 NULL
适合场景 简单数字、固定格式输入 姓名、句子、整行文本

所以可以简单记：

  • 读数字：scanf 很方便，但要检查返回值；
  • 读一行文字：优先用 fgets；
  • 读带空格的字符串：不要用 scanf("%s")；
  • 不要用 gets，它在 C11 中已经被移除，而且非常不安全。

还有一个常见问题：scanf 和 fgets 混用。

解决办法有几种：

  1. 先读整行，再解析；
  2. 统一使用 fgets；
  3. 在 scanf 后按标准方法读掉剩余字符；
  4. 不要用 fflush(stdin)。

中文输入的小提醒

scanf("%s") 读取的是一串非空白字符，它并不懂“一个汉字”和“一个英文字母”的区别，本质上还是按字节读取。

所以：

  • 读带空格的姓名、句子，优先用 fgets；
  • 不要用 scanf("%s") 去读一整句话；
  • 中文乱码时，先检查源文件、编辑器和终端的编码是否一致；
  • 不要在输入缓冲区问题上依赖 fflush(stdin)。

3.3.9 本章代码规范：提示语与错误处理

这一章先集中记住两条规范：

  1. 输入提示语要清楚

    • 推荐：printf("请输入学号：");
    • 不推荐：程序直接停在半途中，用户不知道要输入什么。

  2. 输入失败要处理

    • 推荐：检查 scanf、fgets 的返回值。
    • 不推荐：假设用户一定会输入正确内容。

另外还有几个小习惯：

  • scanf 读取 double 用 %lf，printf 输出用 %f；
  • scanf 读取 char 时，注意是否需要跳过空白；
  • %s 读取字符串时一定要限制宽度；
  • 不要使用 fflush(stdin)；
  • 不要使用 gets；
  • 读整行文本优先考虑 fgets；
  • 混用 scanf 和 fgets 时，要特别小心换行符。
