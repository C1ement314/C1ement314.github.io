1.2.3 逐行认识这个程序

现在咱们把代码拆开，一句一句看。

第一行：#include <stdio.h>

这一行叫预处理指令，以 # 开头。

它的作用是告诉预处理器：

把标准输入输出头文件 stdio.h 的内容包含进来。

stdio.h 是 C 标准库提供的头文件，里面声明了 printf 等输入输出函数。

注意几个细节：

  • #include 不是普通的 C 语句，后面不写分号。
  • 标准库头文件通常使用尖括号 < >。
  • 这一行末尾没有分号，不要画蛇添足。

如果没有包含 stdio.h，编译器可能不知道 printf 是什么，于是给出警告或错误。

第二行：int main(void)

这一行定义了一个叫 main 的函数。

拆开看：

  • int：表示 main 函数返回一个整数（integer）。
  • main：函数名。常规 C 程序通常从 main 函数开始执行。
  • void：表示这个 main 函数不接收参数。
  • {：函数体开始。

初学者要特别注意：

标准 C 中，main 的返回类型通常是 int，不要写成 void main()。

虽然在个别老教材(如谭浩强版C 语言程序设计)或某些编译器中，void main() 可能也能通过，但它不是标准推荐写法，也不利于养成良好习惯。

第三行：printf("你好，世界！\n");

这一行调用 printf 函数，把文字输出到屏幕上。

拆开看：

  • printf：标准库函数，负责格式化输出。print 是“打印”的意思。
  • "你好，世界！\n"：字符串字面量，也就是要输出的内容。
  • \n：转义序列，表示换行。
  • 末尾的 ;：表示一条语句结束。

如果没有 \n，输出可能不会换行，后面的内容会挤在同一行。

第四行：return 0;

这一行结束 main 函数，并把整数 0 返回给运行环境。

通常来说：

  • 0 表示程序正常结束。
  • 非 0 值通常表示出现了某种异常。

第五行：}

这个右花括号表示 main 函数结束。

注意：花括号要成对出现。少一个 } 是很常见的编译错误。

1.3 进阶篇：再懂原理

基础篇让你把程序跑起来了。接下来，咱们把“为什么这么写”讲清楚。

1.3.1 #include 和标准库

C 语言的核心语法里，并没有直接提供“在屏幕上输出文字”的语句。

那 printf 是从哪里来的？

答案是：C 标准库。

C 标准库提供了一批常用函数，例如：

  • printf：格式化输出；
  • scanf：格式化输入；
  • malloc、free：动态内存管理；
  • strlen、strcpy：字符串处理。

这些函数的声明通常放在对应的头文件里：

头文件 常见内容
stdio.h 输入输出函数
stdlib.h 内存管理、程序控制、类型转换等
string.h 字符串处理函数
math.h 数学函数
ctype.h 字符分类与转换

#include <stdio.h> 的作用，就是让编译器在编译当前源文件时知道 printf 的声明。

这里要注意一个容易混淆的点：

包含头文件，不等于把 printf 的实现复制进你的源文件。头文件主要提供声明，真正的函数实现通常在标准库中，由链接器在链接阶段接上。

这也解释了第 0 章的知识：

  • 编译阶段需要知道 printf 的声明；
  • 链接阶段才需要找到 printf 的实现。

1.3.5 中文输出与编码

标准 C 并不规定源文件必须使用哪种编码，但实际开发中常见的是 UTF-8。

如果你输出中文时出现乱码，通常不是 printf 本身的问题，而是编码不一致，例如：

  • 源文件保存成了 GBK，但编辑器或终端按 UTF-8 读取；
  • 源文件是 UTF-8，但终端使用其他编码显示；
  • 控制台字体不支持某些字符。

本教程示例默认使用 UTF-8 编码。

如果遇到中文乱码，可以优先检查：

  1. 源文件保存的编码；
  2. 编辑器或 IDE 的默认编码；
  3. 运行终端的编码设置。

解决编码问题时，要保持“源文件编码”和“读取端编码”一致。

如果暂时不知道怎么排查，也可以向熟悉的同学、老师或社区求助，说明自己的编辑器、操作系统和完整的错误信息。

有些 Windows 环境在把源文件保存为 UTF-8 with BOM 后，中文输出会正常一些；但这并不是通用解决方案，可能给跨平台和后续工具链带来新的麻烦。更稳妥的做法仍然是让源文件、编译器和终端使用一致的编码。

  • 源文件使用 .c 扩展名。

  • 变量和函数命名要有意义。
  • 不使用 void main() 作为标准写法。

错误 1：把 printf 写成 Printf

C 语言区分大小写，printf 必须小写。

错误 3：分号写成中文分号

; 是英文分号，； 是中文分号。C 代码中要使用前者。

错误 4：把 \n 写成 /n

/ 是斜杠，\ 是反斜杠。换行转义序列是反斜杠加 n。

错误 5：运行窗口一闪而过

如果是在某些图形环境中直接双击运行，程序输出完就结束了，窗口可能一闪而过。这通常不是代码错误，而是运行方式的问题。

在 IDE 中运行，或者从终端、命令行运行，通常可以看到输出。

错误 6：中文乱码

先检查源文件编码和终端编码是否一致。本教程示例默认使用 UTF-8。
