2.1 先导：程序为什么需要变量？

假设你要写一个学生管理系统。

程序至少需要记住这些信息：

  • 学号：2025114514
  • 姓名：七平
  • 成绩：95.5
  • 等级：A

如果程序不能把这些数据保存起来，那它每处理一步就要重新问一遍，显然不现实。

所以，程序需要一种“有名字的存储空间”，把数据放进去，之后随时可以通过名字取出来使用。

这个“有名字的存储空间”，就是变量。

你可以把变量想象成一个贴了标签的盒子：

  • 标签：变量名，例如 score；
  • 盒子形状：数据类型，例如 int 或 double；
  • 盒子里的东西：变量的值，例如 95.5。

C 语言有很多数据类型，入门阶段先掌握四个最常用的。

类型 用途 示例

double 双精度浮点数 3.1415926、95.5

int：整数类型

int 用来保存整数，例如人数、年龄、学号、数量。

这里的 95 是整数，不包含小数部分。

float 和 double：浮点数类型

浮点数可以简单理解为“带小数的数字”。

为什么有两个浮点类型？

  • float 是单精度浮点数，占用的空间通常比 double 少，精度也低一些；
  • double 是双精度浮点数，精度通常更高，日常写小数建议优先使用 double。

注意 3.14f 末尾的 f：

  • 3.14f 的类型是 float；
  • 3.14 的类型是 double；
  • 如果写 float price = 3.14;，编译器可能会给出警告，因为 3.14 是 double，赋给 float 可能损失精度。

初学阶段可以这样记：

普通小数优先用 double；确实需要 float 时，字面量后面加 f。

char：字符类型

char 用来保存单个字符，例如字母、数字字符、符号。

注意：

  • 字符字面量用单引号，例如 'A'；
  • 字符串字面量用双引号，例如 "A"；
  • 'A' 是一个字符；
  • "A" 是一个字符串，不是 char。

这是初学者非常容易混淆的一点。

  • C11 标准并没有强制所有平台都必须使用补码，但现实中绝大多数平台使用补码；
  • char 到底是有符号还是无符号，由具体实现决定；

整数还有一个必须知道的问题：溢出。

  • 无符号整数溢出时，结果会按 2 的 N 次方取模，也就是“绕回去”；
  • 有符号整数溢出是未定义行为，不要依赖它产生任何特定结果。

所以，写代码时不要假设整数可以无限大。选择类型时，要考虑数据可能达到的范围。

关于这一点，如果你玩过一些游戏，可能见过 127 或 2147483647 这类数字相关的 bug。这通常是因为某些类型能表示的范围有限。比如在常见的 8 位有符号字符、32 位有符号整数实现中，char 的范围可能是 -128 到 127，int 的范围可能是 -2147483648 到 2147483647。但要注意：char 是否有符号由实现决定，int 也不一定是 32 位。写程序时不能把这些范围当成 C 语言在所有平台上的保证。

很多初学者会惊讶地发现：

这不是 C 语言“坏了”，而是因为计算机使用二进制表示小数。

有些十进制小数，例如 0.1，在二进制中是无限循环小数，无法用有限位数精确表示。于是，程序只能保存一个非常接近的近似值。

2.3.7 本章代码规范：命名与初始化

这一章先集中记住两条规范：

  1. 变量名要有意义

    • 推荐：student_count、average_score、first_letter
    • 不推荐：a、b、c、x1、data2

  2. 能初始化就初始化

    • 推荐：int score = 0;
    • 不推荐：int score; 然后过很久才赋值

另外还有几个小习惯：

  • 一行声明一个变量，通常比 int a, b, c; 更容易阅读；
  • 常量名用全大写加下划线，例如 MAX_STUDENTS；
  • 不要用容易和数字混淆的名字，例如单独的 l 或 O；
  • 类型不匹配时，不要靠编译器“帮你猜”，要显式转换或修改类型。

浮点数存在精度误差，比较时通常判断差值是否足够小，而不是直接判断相等。

2.7 总结与自测

一句话总结

变量是“有名字、有类型、有值”的存储空间；int 存整数，float 和 double 存小数，char 存单个字符，使用前要先声明，最好在声明时初始化。

自测题

  1. 变量通常包含哪三个要素？
  2. int、double、char 分别适合存储什么数据？
  3. 初始化和赋值有什么区别？
  4. sizeof 是函数还是运算符？sizeof(char) 一定等于多少？
  5. 为什么浮点数有时算不准？
  6. 整数除法 5 / 2 的结果是什么？怎样得到 2.5？
  7. const 的作用是什么？
  8. 为什么变量名要有意义？
点击查看参考答案
  1. 类型、名字、值。
  2. int 适合整数；double 适合一般小数；char 适合单个字符。
  3. 初始化是在创建变量时给初值；赋值是修改已经存在的变量的值。
  4. sizeof 是运算符，不是函数；sizeof(char) 一定等于 1。
  5. 因为有些十进制小数无法用二进制有限位数精确表示，计算机只能保存近似值。
  6. 5 / 2 的结果是整数 2；写成 5 / 2.0 或 (double)5 / 2 才能得到 2.5。
  7. 让变量的值在初始化后不能被修改。
  8. 因为代码是写给人看的，有意义的变量名能减少出错，也方便自己和别人读懂代码。
