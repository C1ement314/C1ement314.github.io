15.1.1 RAM 和 ROM 是什么？

理解文件为什么能保存数据，先要知道程序运行时和断电后的区别。

RAM

RAM 是随机访问存储器，通常就叫“内存”。

特点：

  • 程序运行时使用；
  • 读写速度快；
  • 断电后数据会丢失；
  • 局部变量、函数调用、malloc 申请的内存通常都在 RAM 中。

ROM 和持久化存储

ROM 是只读存储器，通常用来保存固件、启动程序等。

不过在日常开发里，我们更常说的是“磁盘、SSD、Flash 等非易失性存储”。

特点：

  • 断电后数据仍然存在；
  • 读写速度通常比 RAM 慢；
  • 文件保存在这些存储设备上；
  • 程序关闭后，文件内容还在。

注意：

不要简单地把 ROM 和硬盘完全画等号。ROM 是非易失性存储器的一类；现代文件通常保存在硬盘、SSD、Flash 等设备上。

15.3.1 文本文件和二进制文件

文本文件保存的是可读字符：

输入缓冲区和文件缓冲区的关系

输入缓冲区和文件缓冲区本质上是同一类东西：

都是标准库在内存中开的临时区域，用来减少频繁的底层读写。

对比一下：

对比项 输入缓冲区 文件缓冲区
数据来源 键盘、标准输入 磁盘文件
管理者 C 标准库 C 标准库
主要目的 减少频繁输入 减少频繁磁盘读写
读取函数 scanf、fgets fgets、fscanf、fread
写入函数 无 fprintf、fputs、fwrite
刷新方式 通常自动 fflush、fclose
相关函数 getchar、scanf fgetc、fgets、fread

相同点：

  • 都是内存中的临时区域；
  • 都会按自己的规则向前移动“读取位置”；
  • 都可能出现“剩余内容”问题；
  • fflush(stdin) 都不是标准做法。

不同点：

  • 输入缓冲区主要和交互式输入有关；
  • 文件缓冲区主要和磁盘 I/O 有关；
  • 文件缓冲区有明确的打开、关闭、刷新流程；
  • 文件缓冲区可以定位、回退、移动到末尾。

  3. "r" 只读，文件必须存在；"w" 只写并清空原内容；"a" 追加写。
  4. 因为它会清空文件原有内容。
  5. 把缓冲区数据写回文件，释放文件资源，并返回关闭状态。
  6. fprintf 多一个文件指针参数，输出到文件而不是标准输出。
  7. fgets 适合按行读取；fscanf 适合按固定格式读取。
  8. 因为 feof 只有在尝试读取到文件末尾之后才为真，容易多读一次；读取函数的返回值更直接。
  9. 文本文件保存可读字符；二进制文件保存内存中的二进制形式，读写更快但跨平台性差。
  10. 不同操作系统路径不同，写死路径会降低可移植性。
  11. fopen、fclose、fprintf、fscanf、fgets、fread、fwrite 等都要检查。
  12. 初学项目适合用简单的文本格式，例如每行“学号 姓名 成绩”。
