11.3.13 本章代码规范：指针命名体现用途，使用前检查空

这一章最重要的两条规范是：

  1. 指针命名体现用途

    • score_ptr、max_ptr、student_ptr；
    • 可以用 _ptr 后缀明确表示它是指针；
    • 不要用 p1、p2 这种不容易看懂的名字。

  2. 使用前检查空

    • 指针可能为空时，先判断 != NULL；
    • 不要解引用空指针；
    • 函数返回指针时，调用者要检查返回值。

其他建议：

  • 指针声明时尽量初始化；
  • 不要使用未初始化的野指针；
  • 不要返回指向局部变量的指针；
  • 指针算术不要越界；
  • 不修改数据时使用 const；
  • 函数返回指针时，明确说明返回值可能为 NULL。

常见误解 FAQ

1. 指针是不是就是地址？

严格说，指针变量保存的是地址；指针是一个变量，不是地址本身。

2. NULL 是不是就是 0？

NULL 是空指针常量，具体实现可能定义为 0 或 (void *)0。不要把它当成普通整数 0 来使用。

3. 数组就是指针吗？

不是。数组名在大多数表达式中会退化为指针，但数组本身是一组连续的元素。

4. p + 1 是不是地址加 1 个字节？

不是。p + 1 会加一个“所指向类型”的大小。

5. 指针越界为什么有时不报错？

因为 C 语言不自动检查数组边界。越界属于未定义行为，可能崩溃，也可能看起来正常。

6. int p 和 int p 有什么区别？

语法上没有本质区别，都表示 p 是 int 指针。推荐写 int *p，更容易避免多变量声明时的误读。

7. char *s = “hello” 为什么不能改？

因为 s 指向的是字符串字面量，通常位于只读区域，修改它是未定义行为。

8. 为什么不能返回局部变量地址？

因为函数返回后，局部变量的生命周期结束，地址可能失效，变成悬空指针。

9. void * 是什么？

void * 是通用指针，可以保存任意对象指针，但不能直接解引用，必须先转回具体类型。

10. 函数指针有什么用？

函数指针可以指向函数，常用于回调、函数表等场景。初学阶段了解即可。

11.7 总结与自测

一句话总结

指针是保存地址的变量；& 取地址，* 解引用；数组元素是连续存放的变量，数组名在大多数表达式中会退化为首元素地址；使用指针前要检查空指针，不要使用野指针，也不要返回局部变量的地址。

自测题

  1. 变量、地址、值分别是什么？
  2. &score、p、*p、&p 分别是什么意思？
  3. 为什么 scanf 需要写 &age？
  4. 指针加 1 时移动多少字节？
  5. 数组名和指针是什么关系？
  6. scores[i] 和 *(scores + i) 有什么关系？
  7. 空指针、野指针、悬空指针有什么区别？
  8. const int *p 和 int * const p 有什么区别？
  9. 函数返回指针时要注意什么？
  10. 为什么 p_arr + 1 可以用于数组遍历，而 p_score + 1 不能用于数组遍历？
点击查看参考答案
  1. 变量是有名字、有类型、有值、也有地址的存储空间；地址是变量在内存中的位置；值是变量保存的数据。
  2. &score 是 score 的地址；p 保存地址；*p 是 p 指向的值；&p 是指针变量自己的地址。
  3. 因为 scanf 需要知道把输入数据存到哪个地址。
  4. 移动一个“所指向类型”的大小，例如 int * 通常移动 sizeof(int) 字节。
  5. 数组名在大多数表达式中会退化为指向首元素的指针，但数组本身不是指针。
  6. scores[i] 等价于 *(scores + i)。
  7. 空指针明确不指向有效对象；野指针是未初始化指针；悬空指针指向已经失效的内存。
  8. const int *p 不能通过 p 修改数据，但可以改指向；int * const p 可以修改数据，但不能改指向。
  9. 要保证返回的指针仍然有效，并说明是否可能返回 NULL；调用者要检查。
  10. p_arr 指向数组元素，可以按元素移动；p_score 指向单个变量，虽然可以形成 p_score + 1 这样的指针值，但它不构成合法数组范围，不能解引用，也不能用于数组遍历。

挑战题

用指针重写一个“班级成绩分析器”。

要求：

  1. 用数组保存至少 8 位学生的成绩；
  2. 用 const int * 遍历数组并计算总分；
  3. 用 int * 修改数组中的成绩，例如给所有人加 5 分，最高不超过 100；
  4. 写一个函数返回最高分所在的位置；
  5. 用指针相减计算最高分学生的下标；
  6. 写一个交换函数，通过指针交换两个成绩；
  7. 所有返回指针的函数都要说明是否可能返回 NULL，并在调用处检查；
  8. 画出变量、地址、数组、指针之间的关系图。
