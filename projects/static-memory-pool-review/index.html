项目名称：固定大小静态内存池分配器

作者：七平

语言：C

涉及知识点：静态数组、单向链表、指针算术、内存对齐、O(1) 分配与释放

一、项目背景

在裸机环境或资源受限环境中，有时不能使用标准库的 malloc 和 free。

这时可以自己实现一个简单的内存池分配器：

  • 从一片连续的静态内存中分配固定大小的块；
  • 用单向链表管理空闲块；
  • 分配和释放都只操作链表头部；
  • 不依赖动态内存管理函数。

这个项目的目标就是实现这样一个固定块大小的内存池。

  3. 初始化内存池，建立空闲块链表；
  4. 实现申请内存函数；
  5. 实现释放内存函数；
  6. 测试连续性、复用性和耗尽保护；

5. 为什么用 union 包一层

unsigned char 数组本身不保证具有指针类型的对齐。

Block 里包含指针，所以内存池最好有指针对齐。

用 union 可以让内存池同时具有：

  • 适合 void * 的对齐；
  • 连续的字节数组空间。

九、总结

这个项目虽然很基础，但是也是巩固下列C语言知识的重要项目：

  • 静态数组；
  • 单向链表；
  • 指针算术；
  • 内存对齐；
  • O(1) 分配和释放；
  • 不使用 malloc / free 的内存管理思路。

核心思想是：

用一条空闲链表，把连续内存切成固定大小的块，申请时摘头，释放时头插。

它不解决所有内存管理问题，但在固定块、资源受限的场景下，是一个简单又有效的方案。
